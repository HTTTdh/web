# 📝 Blog Web Application

Đây là một ứng dụng web blog đơn giản được xây dựng với mục đích học tập, cho phép người dùng thực hiện các chức năng CRUD (Create, Read, Update, Delete) đối với bài viết và bình luận. Ứng dụng hỗ trợ xác thực bằng tài khoản Google.

## ✨ Tính năng

- Đăng nhập, đăng kí (Spring Security)
- Tạo, xem, chỉnh sửa, xoá bài viết
- Thêm và xoá bình luận cho bài viết
- Chỉ người tạo bài viết/bình luận mới có quyền chỉnh sửa hoặc xoá
- Giao diện động hiển thị bằng Thymeleaf

## 🛠️ Công nghệ sử dụng

- **Spring Boot** – Xây dựng backend
- **Spring Security + OAuth2** – Xác thực và phân quyền, hỗ trợ đăng nhập Google
- **Thymeleaf** – Giao diện người dùng (UI)
- **Maven** – Quản lý thư viện
- **H2 / MySQL** – Cơ sở dữ liệu (tùy cấu hình)
- **Cloudinary** - Lưu hình ảnh và trả về url
